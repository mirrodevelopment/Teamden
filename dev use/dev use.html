REST API Endpoint Specifications

Complete HTTP API interface available on port 8080.

MethodEndpointAuth RequiredDescription
GET /api/dev/tables No Live introspection of all database tables and column schemas
GET /api/dev/tables/{name}/data No Live rows from database table (SELECT * FROM table LIMIT 50)
GET /api/dev/users No Live user accounts, roles, and developer credentials from DB
GET /api/dev/overview No Database product version, table counts, and runtime status
POST /api/setup/register-company No Register new company workspace and Owner account
POST /api/auth/login No Authenticate user with JSON {"email": "...", "password": "..."}
POST /api/auth/logout Yes Terminates authenticated session and clears cookie
GET /api/auth/session Yes Returns user profile, active role, and organization
GET /api/auth/csrf No Retrieves XSRF-TOKEN cookie
GET /api/dashboard/summary Yes KPIs, attendance metrics, open tasks, recent activity
GET /actuator/health No System health probe (Returns HTTP 200 UP)

Developer Commands & Launcher

Pre-configured scripts to run, build, and test Teamden.

🚀 One-Click Launcher (start.bat)

Starts PostgreSQL service, verifies port 8080, launches background Chrome monitor, and streams Spring Boot logs.

Executes all integration and unit test suites via Maven Wrapper.

.\mvnw.cmd test

Verifies all Java classes and copies static resources to target directory.

.\mvnw.cmd compile

Starts PostgreSQL 17 Windows service via net start or pg_ctl.

net start postgresql-x64-17
