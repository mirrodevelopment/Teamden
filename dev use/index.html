REST API Endpoint Specifications

Complete HTTP API interface available on port 8080.

Method Endpoint Auth Required Description
GET /api/dev/tables No Live introspection of all database tables and column schemas
GET /api/dev/tables/{name}/data No Live rows from database table (SELECT * FROM table LIMIT 50)
GET /api/dev/users No Live user accounts, roles, and developer credentials from DB
GET /api/dev/overview No Database product version, table counts, and runtime status
POST /api/setup/register-company No Register new company workspace and Owner account
POST /api/auth/login No Authenticate user with JSON {"email": "...", "password": "..."}
POST /api/auth/logout Yes Terminates authenticated session and clears cookie
GET /api/auth/session Yes Returns user profile, active role, and organization
GET /api/auth/csrf No Retrieves XSRF-TOKEN cookie
GET /api/projects/{id}/overview No Project flow overview: specs, milestones (01-09), work status, and decisions
GET /api/projects/{id}/tasks No Project flow task registry: milestone grouping, subtasks, and blocker tracking
GET /api/projects/{id}/documents No Project flow knowledge base: library categories, briefs, and notes viewer
GET /api/projects/{id}/activity No Project flow activity feed: milestone events, comments, and audit timeline
GET /api/dashboard/today Yes Today Kanban board view: columns (Now, Next, Later), task items, ticking date
POST /api/tasks Yes Universal task creation with project association, assignee, and priority
GET /api/tasks/options Yes Live project and assignee options for Universal Create modal
GET /api/employees/directory Yes Workspace people directory: 2-column cards, member counts, and ownership breakdown
GET /api/employees/{id} Yes Employee profile detail: owned responsibilities, work in motion, collaborations
POST /api/employees Yes Invite / create employee with department, role, and initial responsibilities
GET /api/employees/roles Yes Workspace role catalog (Owner, Admin, Manager, Lead, Employee, Guest)
GET /api/employees/structure Yes Interactive organizational hierarchy tree from executive board down to teams
GET /api/notifications Yes Inbox notifications: Attention Queue, Notification Register, and Action in Focus
PUT /api/notifications/{id}/read Yes Mark individual notification as read
POST /api/notifications/mark-all-read Yes Bulk mark all notifications as read for current user
GET /api/daily-updates/today Yes Today's standup update (completed, next, blockers, health, velocity, attachment)
POST /api/daily-updates Yes Publish or save draft daily standup update with optional image reference
GET /api/daily-updates/suggestions Yes 1-click auto-fill suggestions derived from today's completed tasks
GET /api/search Yes Global discovery & search with connected context extraction across all entities
GET /api/calendar/full-data Yes Unified calendar data: events, sources, commitments, team availability, backlog
GET /api/activity/events Yes Audit feed & chronicle timeline with category key and date range filtering
GET /actuator/health No System health probe (Returns HTTP 200 UP)

Developer Commands & Launcher

Pre-configured scripts to run, build, and test Teamden.

🚀 One-Click Launcher (start.bat)

Starts PostgreSQL service, verifies port 8080, launches background Chrome monitor, and streams Spring Boot logs.

.\start.bat
🧪 Run Automated Tests

Executes all integration and unit test suites via Maven Wrapper.

.\mvnw.cmd test
📦 Compile Project

Verifies all Java classes and copies static resources to target directory.

.\mvnw.cmd compile
🐘 Start PostgreSQL Service Manually

Starts PostgreSQL 17 Windows service via net start or pg_ctl.

net start postgresql-x64-17
